## Поля документов в коллекции "reminders":
### "periodic":
{
    'type': 'static', # (может быть ещё random)
    'unit': 'days', (может быть weeks, months, years)
    'number': 8 (количество)
}
или:
{
    'type': 'random',
    'mindays': 6,
    'maxdays': 11
}
В этом случае при достижении 'date_activation' - напоминалка откинется на случайное число дней из диапазона.

### "oneshot" 
Однорозовая напоминалка. Отработать, и архивировалаться. Не требует поля "periodic"

### "link_with_wekan_card"
При создании напоминалки должен быть соответствующий вопрос (чекбокс). Значение поля - _id карточки полученный от post_to_wekan(). Если поле в карточке есть (напоминалка связана с карточкой) - сервис следит за наличием этой карточки в базе 'wekan', коллекция 'cards'. Если поле связанной карточки 'archived' переведено в true или карточка исчезла из базы wekan - откинуть её согласно правил.

### "archived"
любую карточку можно архивировать вручную либо это произойдёт автоматически. такие карточки не отображаются в общем случае, но их можно просмотреть в специальном разделе
