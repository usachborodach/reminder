## Поля документов в коллекции "reminders":
### "auto_postpone"
bool
если True напоминалка отправлятся в векан и автоматически откладывается согласно "periodic"
по таким напоминалкам мы не следим за карточками а просто сыпем с определённой периодичнстью
link_to_wekan_card для таких - None
если False - Значение поля - _id карточки полученный от post_to_wekan()

### "sended"
флаг отправлено/не отправлено

### "activate_datetime"
датавремя когда должна сработать напоминалка

### "create_datetime"
датавремя создания

### "last_send_datetime"
датавремя последней отправки

### "periodic":
{
    'type': 'static', # (может быть ещё random)
    'unit': 'days', (может быть weeks, months, years)
    'number': 8 (количество)
}
или:
{
    'type': 'random',
    'mindays': 6,
    'maxdays': 11
}
В этом случае при достижении 'date_activation' - напоминалка откинется на случайное число дней из диапазона.

### "oneshot" 
bool. Признак однорозовой напоминалки. Отработать, и архивироваться. Не требует поля "periodic"

### "link_to_wekan_card"
При создании напоминалки должен быть соответствующий вопрос (чекбокс). Значение поля - _id карточки полученный от post_to_wekan(). Если поле в карточке есть (напоминалка связана с карточкой) - сервис следит за наличием этой карточки в базе 'wekan', коллекция 'cards'. Если поле связанной карточки 'archived' переведено в true или карточка исчезла из базы wekan - откинуть её согласно правил.

### "archived"
любую карточку можно архивировать вручную либо это произойдёт автоматически. такие карточки не отображаются в общем случае, и они не срабатывают, но их можно просмотреть в специальном разделе

### "board"
доска wekan в которую будет произведена отправка
